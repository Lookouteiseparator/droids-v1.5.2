# Changelog

All notable changes to Droids are documented here.

## 1.5.2 - 2026-10-24

### Added

- Device manager improvements.
- New presets in Devices.

### Changed

- Faster startup and lower memory use.
- Cleaner logging with timestamps.

### Fixed

- Crash on exit in rare cases.
- Settings not persisting after an update.

## 1.0.0 - 2026-08-30

### Added

- First public release: Android ADB toolkit.
- Portable build with no installer.
- Configuration and profiles.
- Documentation and example workflow.
